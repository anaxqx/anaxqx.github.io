# Xinqi Xiong

Personal academic homepage using the Jon Barron website template.

Open `index.html` locally or serve this folder with `python3 -m http.server 8000`.

Publication entries are in `index.html`. Replace the paper thumbnails in `images/` with higher-resolution versions using the same filenames. The CV is `data/Xinqi_Xiong_CV.pdf`.

Template credit: https://jonbarron.info/
